AutoIndia Motors

Find your next car. Plan your drive. Make it yours.

AutoIndia Motors is a web-based automotive platform that makes it easier for users to explore cars and take the next step toward finding their preferred vehicle. Users can browse car models, book home test drives, explore customization options, calculate EMIs, and contact the team for enquiries—all in one place.

I built this project to bring useful car-buying features together in a simple, user-friendly website while improving my skills in web development.

Live Demo

Website: https://auto-india-motors.onrender.com/

Features

- Explore Cars – Browse available car models and view their details.
- Home Test Drive Booking – Request a test drive from the comfort of your home.
- Car Customization – Explore available vehicle customization options.
- EMI Calculator – Estimate monthly payments based on loan details.
- Enquiries and Contact – Submit enquiries and get in touch for more information.
- User Account Features – Access the available login and profile functionality.

Technologies Used

The project uses the following technologies:

- HTML5 – Structures the web pages.
- CSS3 – Styles the interface and makes the website visually appealing.
- JavaScript – Adds interactive functionality.
- Node.js – Runs the server-side application.
- Express.js – Handles server routes and application requests.
- MongoDB – Stores application data.
- Render – Hosts the deployed website.

Run the Project Locally

Follow these steps to run the project on your computer.

1. Clone the repository**

```bash
git clone https://github.com/Gangadhar8080/Auto-India-Motors.git
```

2. Open the project folder**

```bash
cd Auto-India-Motors
```

3. Install the dependencies**

```bash
npm install
```

4. Configure environment variables**

Create a `.env` file in the project root and add the configuration required by your application, such as your MongoDB connection string and port.

Never upload real passwords, database credentials, or secret keys to GitHub.

5. Start the application**

Use the start command defined in your `package.json`. For example, if the script is configured as `start`:

```bash
npm start
```

Open the local URL shown in your terminal.
